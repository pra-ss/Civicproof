# CivicProof

### Proof Before "Resolved"

CivicProof is a civic complaint verification platform designed to prevent complaints from being incorrectly marked as resolved.

## Key Features

- Citizen complaint submission
- Photo evidence
- SHA-256 evidence fingerprinting
- Officer dashboard
- Resolution proof requirement
- Before/after evidence verification
- Location consistency checks
- Citizen verification
- Dispute and escalation workflow
- Public resolution receipts
- Tamper detection demonstration
- Proposed blockchain-backed architecture

## Prototype

This prototype currently simulates the verification layer client-side using SHA-256 hashing.
